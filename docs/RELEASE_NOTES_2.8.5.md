# Codex Goal Supervisor 2.8.5

## Candidate scope

- Preserve the verified 2.5-current business surface.
- Preserve one concise confirmed North Star across a shallow program outline
  and dependency-ready 2-24 hour phase Goals.
- Keep the complete structured phase definition separate from its native Goal
  projection when the complete definition exceeds the Goal UI limit.

## Blackbox-driven fix

The fixed Luna Max blackbox supplied a complete canonical P1 definition, but
its deterministic renderer produced 6,345 characters and was rejected by the
2,000-3,500 character native Goal limit. The candidate also ignored a separately
authored compressed phase objective.

This candidate accepts a top-level authored `goal_mode_objective` only when:

- it is 2,000-3,500 characters;
- the complete structured `goal_definition` independently passes every field,
  research, node, deliverable, and acceptance requirement.

The full definition is never truncated. A long objective cannot hide missing
structure. The installed Skill and README document the two-layer contract.

The local roadmap process now passes its generated shutdown token as one
`--token=<value>` argument, so a valid URL-safe token beginning with `-` cannot
be misparsed as a CLI option and fail intermittently during startup.

## Release boundary

This remains a local candidate. It is not published until source,
extracted-package, edition-boundary, selftest, and fixed Luna Max blackbox
verification pass.
